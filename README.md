# XPlace Core — Studium

Protótipo do site da XPlace, uma empresa fictícia de software para controle de hardware, criado em grupo para um trabalho escolar. Feito com HTML, CSS e JavaScript puro, sem frameworks.

**Acesse:** https://lucianopdev.netlify.app/projetos/xplace/

## Páginas

| Página | Arquivo | Conteúdo |
| --- | --- | --- |
| Login e cadastro | `login.html`, `cadastro.html` | Entrada no protótipo com validação dos campos |
| Dashboard | `index.html` | Página inicial com carrossel de imagens |
| XPlace Core | `core.html` | Apresentação do software principal |
| XPlace Studio | `studio.html` | Apresentação da ferramenta de criação |
| Loja | `loja.html` | Catálogo de produtos em vitrines com rolagem |
| Sobre nós | `sobre.html` | História da empresa e fundadores |
